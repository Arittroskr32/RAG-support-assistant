# API access

## Ke use korte parbe
Pro ar Enterprise plan e API access ache. Admin ra Settings, Developers theke key banate paren.

## Key banano
Protita key r emon naam din jate bojha jay ki kaje lage, jemon inventory sync. Pura key ekbari dekhano hoy, tai safe jaygay copy kore rakhun.

## Key rotate kora
Notun key banan, apnar integration update korun, tarpor purono key delete korun. Koek mash por por ar team er keu chole gele key change kora bhalo.

## Rate limit
Protita key te minute e koto request kora jabe tar limit ache. Limit par hole API rate-limit response dey, tokhon ektu wait kore abar try korun.

## Webhook
Webhook order ar payment er event apnar server e pathay. Protita request signed thake, tai apnar server check korte pare sheta amader kach theke esheche.

## Developer support
API niye proshno Developers page er support form e pathan. Request er time ar je error peyechen sheta likhun.
