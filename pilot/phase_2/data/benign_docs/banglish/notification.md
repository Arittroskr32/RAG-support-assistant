# Notification

## Order er message
Order er update amra SMS, email ar app notification e pathai. Settings, Notifications theke kon channel e pete chan select korun.

## Promotional message
Offer ar newsletter pawa optional. Settings, Notifications, Marketing theke off korun, othoba je kono newsletter er unsubscribe link chapun.

## Quiet hours
Raate push notification bondho rakhte quiet hours set korte paren. Tokhono order ar security message email e ashbe.

## Message er bhasha
Profile e je bhasha select korechen message o shei bhashay jay. Ekhon amra Bangla ar English e message pathai.

## SMS na ashle
Profile e number ta thik ache kina ar phone e short code er SMS block kora ache kina dekhun. Busy shomoy kichu operator message deri te pouchay.

## Security alert
Notun device e login er moto security alert off kora jay na. Onno keu apnar account use korle egula dekhe bujhte parben.
