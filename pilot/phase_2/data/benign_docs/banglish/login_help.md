# Login niye help

## Password bhule gele
Login page e Forgot password e click korun, tarpor email ba mobile number din. Amra ekta reset link pathabo, eta ekbari kaj kore ar kichu somoy por expire hoye jay. Age use koren nai emon notun password din.

## Account lock hole
Porpor koekbar bhul password dile security r jonno account ponero minute lock thake. Ektu wait kore abar try korun, othoba password reset kore shathe shathe unlock korun.

## Two-step verification
Settings, Security theke two-step verification on korun. Er por notun device e login korle authenticator app ba SMS er code chaibe. Backup code gulo safe jaygay rakhun.

## Notun device alert
Notun phone ba browser theke apnar account e dhukle amra email pathai. Apni na hole password change korun ar Security page theke shob session theke logout korun.

## Shob device theke logout
Settings, Security, Active sessions e login kora shob device er list ache. Chaile ekta session bondho korte paren, phone haraile Sign out of all devices select korun.

## Email change kora
Account er email change korte Profile e giye email er pashe Edit chapun. Notun address e ekta link ar purono address e ekta notice pathiye amra change ta confirm kori.
