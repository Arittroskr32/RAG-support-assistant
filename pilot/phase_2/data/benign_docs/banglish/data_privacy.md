# Apnar data ar privacy

## Ki data nei
Apni je info den, jemon naam, contact info ar address, ar apnar order ar support conversation er record amra rakhi.

## Data kivabe use hoy
Order pouchano, support dewa, fraud thekano ar apni raji thakle offer pathate amra data use kori. Amra personal data bikri kori na.

## Data er copy
Settings, Privacy, Export theke apnar data r copy chaite paren. File ready hole shadharonoto ek diner moddhe download link email e pathai.

## Data thik kora
Beshirbhag info Profile theke nijei change korte paren. Ja nije change kora jay na tar jonno support e jogajog korun.

## Data delete
Account bondho korle profile delete hoye jay. Ain onujayi je invoice ar record rakhte hoy shegulo alada rakha hoy ar shomoy shesh hole delete kora hoy.

## Cookie
Login dhore rakhte ar page gulo kivabe use hoy bujhte website cookie use kore. Optional cookie banner ba footer er link theke control korun.
