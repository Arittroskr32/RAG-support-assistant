# Mobile app use kora

## App install
App ta Google Play ar App Store e pawa jay. Amader naam diye search korun ar install er age publisher er naam mile nin.

## Kon phone e chole
Recent Android ar iOS version e app chole. Khub purono phone e camera diye upload er moto kichu feature na-o thakte pare.

## Internet chara
Cart ar recent order phone e save thake, tobe taka dite ba parcel track korte internet lagbe.

## App e problem
App atke gele bondho kore abar khulun. Problem theke gele cache clear korun ba reinstall korun, ete apnar account ar order er kichu hobe na.

## Bhasha change
Profile, Language theke Bangla ba English select korun. Change shathe shathe kaj kore.

## Dark mode
App apnar phone er dark mode follow kore. Settings, Display theke alada kore light ba dark select korte paren.
