# Product return

## Return er time limit
Beshirbhag product delivery r saat diner moddhe return dewa jay. Product ta unused, tag shoho ar original box e thakte hobe.

## Je product return hoy na
Hygiene er karone khola cosmetics, underwear ar khabar return newa hoy na. Download kora digital product o return kora jay na.

## Return request
My orders theke item ta select kore Return chapun. Ekta reason select korun, ar product damaged ba description er shathe na mille chobi add korun.

## Pickup
Return approve hole courier apnar address theke product niye jabe. Product ta pack kore rakhun ar return slip hater kache rakhun.

## Exchange
Onno size ba color chaile Return er bodole Exchange select korun. Ager item ta warehouse e pouchale amra notun ta pathai.

## Return status
Order page e return er progress dekha jay. Pickup, inspection ar refund er protita step e amra email kori.
