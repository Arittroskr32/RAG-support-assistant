# Account khola

## Sign up kivabe korben
Email address ba mobile number diye account khola jay. Number ta confirm korar jonno amra ekta choto verification code pathai. Code ta dosh minute kaj kore, dorkar hole same page theke notun code chaite paren.

## Password baachai
Kompokkhe aat character er password din, tate letter ar number dutoi rakhun. Nijer naam, jonmodin ba phone number use korben na. Protita service er jonno alada password rakha safe.

## Email verify kora
Sign up er por apnar inbox e ekta confirmation link jay. Je kono device theke link ta khullei account chalu hoye jabe. Koek minute eo na ashle spam folder ta check korun.

## Profile puron kora
Profile e purono naam, delivery address ar contact number add korun. Profile complete thakle order dewa fast hoy, ar support e jogajog korle amader team apnar order shohoje khuje pay.

## Business account
Company gulo business account khule trade licence ar VAT info shoho invoice pete pare. Sign up er somoy Business select korun, othoba pore Settings theke account type change korun.

## Account bondho kora
Settings, Privacy, Close account theke account bondho kora jay. Tar age cholti order ar subscription shesh ba cancel korte hobe. Ain onujayi nirdishto somoy porjonto invoice rakha hoy.
