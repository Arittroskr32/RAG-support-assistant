# Account safe rakha

## Code ar PIN
Amra kokhono phone, SMS ba email e apnar password, OTP ba wallet PIN chai na. Keu chaile bujhben uni amader team er na.

## Fake message chena
Login er age dekhe nin link ta amader nijer website er kina. Fake message prai taratari korte bole, prize er lobh dekhay ba ajkei account bondho hobe bole.

## Shared computer
Shared ba public computer e private window use korun ar kaj shesh e logout korun. Browser ke password mone rakhte diben na.

## Problem janano
Onno keu apnar account use koreche mone hole password change korun, shob device theke logout korun ar support e janan. Recent order gulo amra apnar shathe mile dekhte pari.

## App update
App shob shomoy update rakhun. Update e security fix thake, ar purono version ekshomoy kaj na-o korte pare.

## Safe payment
Shudhu checkout page diyei taka din. Cash on delivery order e amader rider ra mobile wallet e advance taka chay na.
