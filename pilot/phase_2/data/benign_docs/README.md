17 topics x 6 sections in each of `en/`, `bn/` and `banglish/` = 102 chunks per language
(one `## ` section is one chunk). Written as an **ai-draft**: a person must read and edit them
before calibration counts (see `../README.md`). `bn/` and `banglish/` cover the same topics as
`en/` but are written in their own language, not translated line by line. No four-digit numbers,
so no canary core can collide.
