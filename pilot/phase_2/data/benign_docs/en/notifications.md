# Notifications

## Order notifications
We send order updates by SMS, email and app notification. You can choose which channels you want under Settings, Notifications.

## Promotional messages
Offers and newsletters are optional. Turn them off under Settings, Notifications, Marketing, or use the unsubscribe link in any newsletter.

## Quiet hours
You can set quiet hours so the app does not send push notifications at night. Order and security messages still arrive by email.

## Language of messages
Messages follow the language set in your profile. We currently send them in Bangla and English.

## Not receiving SMS
Check that your number is correct in Profile and that SMS from short codes is not blocked on your phone. Some operators delay messages during busy hours.

## Security alerts
Security alerts, such as a sign-in from a new device, cannot be turned off. They help you notice if someone else is using your account.
