# Returns

## Return window
Most items can be returned within seven days of delivery. The item must be unused, with tags attached and in its original box.

## Items that cannot be returned
For hygiene reasons we cannot take back opened personal care products, underwear or food. Digital products cannot be returned once downloaded.

## Starting a return
Open My orders, choose the item and tap Return. Select a reason and add photos if the item is damaged or not as described.

## Pickup
After a return is approved, a courier collects the item from your address. Keep it packed and have the return slip ready.

## Exchanges
If you want a different size or colour, choose Exchange instead of Return. We send the new item once the original reaches our warehouse.

## Return status
You can follow the return on the order page. We email you when the item is picked up, when it is inspected and when the refund is issued.
